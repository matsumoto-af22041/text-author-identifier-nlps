# 044: 補助スライドの整理と本編の細部の修正

## Expected Deliverables & Design Policy

- 背景：042 の版への研究者のフィードバック（2026-11-24）．番号は 042 の版（本編 24 枚，参考文献 24，補助 S1～S17）．方針は `plans/research-context.md` の「発表の軸」（補助スライドは質問への反論の材料）に従う．
- 新しい数値・主張は加えない．追加する主張は `full_006` 等の既存の出力でスクリプトにより確認し，確認できないものは書かない．

### 補助スライドの全体

- **表示の形式**：各補助スライドの見出しの直下に，想定される質問の文だけを書く（例：「重心法と k-NN 法のどちらが良かったか」）．「想定質問：」「答え：」の文字列と「Q11」等の番号はスライドに出さない（発表準備を匂わせる表示をしない）．質問の番号と qa_defense_matrix.md との対応は発表者ノートにのみ残す．
- **並べ順**：本編のスライドの順に対応するよう並べ替える（その補助スライドが補う本編のスライドの番号の昇順．同じ本編のスライドに対応するものは関連の強い順）．並べ替えの基準を storyline に書き，S 番号を振り直して storyline ・ qa ・ README ・ `scripts/check_slides.py` の参照を一括更新（旧番号の残り 0 を確認）．
- **指標の絞り込み**：補助スライドでも，想定質問に答えるのに要らない要素は載せない．本編と同じく作家別 MAP の平均と作家別正解率の平均だけを使い，作家別 F 値の平均・ MRR 等を他の補助スライドから外す（S1 の 6 枚の図から F 値のパネルを外して再描画，S7 の表・ノートの別の指標も外す．他の補助スライドも同様に点検）．
  - 例外：基準値の根拠（S17）は，F 値・ MRR の基準値の式を後述の「指標を 2 つに絞った理由」のスライドに必要な範囲でのみ残す．$\Delta S$ の補助スライド（S10）は $\Delta S$ 自体についての質問への答えのため残す．
- **新設：指標を 2 つに絞った理由**（1 枚，「なぜ F 値や MRR を使わないのか」への答え）：作家別 MAP の平均（類似度の順位のみに依存し，推論方式と類似度の値の分布によらず特徴量間で比較できる）と作家別正解率の平均（著者の判定そのもの．作家別の単純平均のため Test の作家構成によらない）を主指標とした理由（research-context の「主評価指標」の記述から）．F 値・ MRR を外しても結論が変わらないこと（作品間分割，$L = 500$ ，重心法，間引きありで A～D の順位が作家別 F 値の平均・ MRR でも同じか）を `full_006` で確認し，同じならその事実を書く．同じでなければ，違いをそのまま報告して書き方を相談（勝手に書かない）．

### 本編の修正

- **本編から補助スライドの番号への参照をなくす**（「（補助 S15）」等）．補足が必要な箇所は，余白に簡潔な説明を書く．
  - **11**（A の結果・考察）：「補助 S15」の参照の代わりに，下の余白に底本の表記揺れの要点を簡潔に（例：同じ作家でも作品ごとに「云う / 言う」等の表記が異なり，文字 Bi-gram はその差を拾いうる．既存の値は S15 から）．
  - **13**：「補助 S1」の表記を削除．
  - 他の本編のスライドも点検し，補助スライドの番号の参照を 0 にする（発表者ノートには残してよい）．
- **17**（C の結果・考察）：棒グラフの棒の幅を狭くする（`scripts/plot_slide_figures.py` のグラフ C．A ・ B のグラフ（a_ablation ， b_ablation）と見た目をそろえ，必要なら 3 つとも同じ幅にそろえる）．描画値は不変であることを確認．
- **23**（結論と限界）：限界の「Test の約半数が漱石（単純平均で対処）」は対処済みで限界ではないため削除．代わりに research-context の「既知の限界」にある残りの偏り（作品間分割では Test の作家だけが Train に 1 作品分しか持たず，作品の多様性の差は間引きでも消えない）を簡潔に書く．
- **24**（参考文献）：「外部文献は引用しない」等の方針の記述を削除し，文献の一覧だけにする．

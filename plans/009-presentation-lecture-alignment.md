- 書き換え対象と内容：
  - **全文書共通**：
    - 「講義準拠」と書く箇所は講義資料に式または定義がある項目（tf，idf，コサイン，Jaccard の重なり率の概念，品詞分類，LSI の分解，F 値，MRR，代表文書による分類）のみに限定し，頁番号を併記．

    - 「Ticket N」「Ticket QA-1」表記を `plans/00N-*.md` の 3 桁番号に置き換え．存在しない `llm-rules.md` ・ `llm-context.md` への参照を `.claude/rules/research-coding.md` ・ `plans/research-context.md` に置き換え．
  - **`presentation/qa_verification_instructions.md`**：
    - Q6：Min-Max 正規化の既定採用を撤回．回答の軸は「正規化は中立ではなくブロックの重み付けを暗黙に決める操作であり，実測で選んだ」．010 の実測値（確定情報）：二乗ノルム割合は字種を含む旧案で字種が約 99%，Min-Max 適用時は Bi-gram が 88～96% を占め，既定仕様（Bi-gram + 記号の相対頻度，第 5 回 p.12）のみ Bi-gram / 記号 = 0.57 / 0.43（ $L = 500$ ），0.52 / 0.48（1000）と単一ブロックに支配されない．平均文長は文末記号率（ $= 1 / \text{平均文長}$ ）として保持．字種構成比は類似度から外し底本の交絡の考察用記述統計に使用．Min-Max（Han, Kamber & Pei (2011)）と Bi-gram のみ・記号のみはアブレーション．Z-score は削除．再現コマンド `uv run python scripts/investigate_a_scale.py` を併記．
    - Slide 5-6：上記の 3 構成の二乗ノルム割合の表を「正規化なしを選んだ根拠」として追加．
    - Q7：対象品詞を付属語（助詞・助動詞，第 2 回 p.11）に変更．接続詞・連体詞・感動詞はアブレーション．補助記号は対象外（句読点は A が担当）．第 5 回 p.11 で不要語とされる語を逆に用いる対比を追記．
    - Q8：idf は講義定義 $\log \frac{N}{\text{df}(t)}$ のみ． $+1$ を「平滑化」と呼んでいた記述を削除し， $\text{df} = N$ の語の重み 0 は第 5 回 p.11 の不要語の定義と整合することを回答とする．
    - Q9：射影を $Z = X V_K \Sigma_K^{-1}$ （講義第 5 回 p.37「 $V$ で変換し $U$ で比較」，式の出典は Manning et al. (2008) §18.4）に変更． $Z = X V_K$ はアブレーション．「累積寄与率」は「上位 $K$ 個の特異値の二乗和の比率」と言い換え．
    - Q10：「なぜ Jaccard / Dice を使わないのか」に差し替え．回答：講義の Jaccard は「文中の単語の重なり率」（第 2 回 p.45）で有無のみを見る．本研究の主役の付属語は数百字のチャンクにほぼ必ず出現するため有無では作家を区別できず，構想発表（p.4）でもコサインでの比較を示した．根拠の数値は 007 の B の特徴のチャンク出現率（要計測）．重み付き版の数値（一致率 99.3%・98.0% 等）と $D = 2J / (1 + J)$ の議論は削除．
    - Q11：「重心法」は第 2 回 p.48 の代表文書による分類，$k = 1$ は第 5 回 p.25 の類似度順位の最上位，作家別上位 $k$ 平均は独自設計，$k$-NN の一般論は Manning et al. (2008) Ch. 14，と出典を区別．
    - Q12：マクロ F1 の出典（Manning et al. (2008) §13.6）と，同点を誤判別として扱う集計規則（008）を追記．
    - 新規質問「C（TF-IDF）より B が良いのは語の種類のせいか，重み付けのせいか」：B の内容語対照条件（同一表現で語の種類だけ差し替え）で分離した，という回答．
    - 新規質問「講義で不要語とされる語をなぜ使うのか」：Core Message の説明と，先行研究（Mosteller & Wallace (1964) 等）．
  - **発表の軸の差し替え（全文書）**：`plans/research-context.md` の Core Message「情報検索では捨てる語が，著者識別では手がかりになる」を発表全体の軸に据える．
    - Slide 1 または 2 の直後に導入スライドを追加：講義第 5 回 p.14（『坊っちゃん』頻度上位は て・だ・た・は・を…），p.15（助詞・助動詞を除くと する・おれ・云う…），p.16（tf・idf 順では 山嵐・シャツ…）を引用し，「講義はこの上位語を不要語（p.11）として捨てた．本研究はその捨てられた側で著者を見分ける」と問いを立てる．本コーパスでの再現図は 003 の `top_function_words` の出力（要計測）．

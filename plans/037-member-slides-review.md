# 037: 担当から上がったスライドの確認（修正案の一覧）

## Expected Deliverables & Design Policy

- 対象：`presentation/自然言語処理システム_課題発表_2026-11-26.pptx` （内容の確認の主）と同名の `.pdf` （見た目の確認用）．git 管理外のファイル．
- 基準：`presentation/presentation_storyline.md` （036 で組み替えた新構成），`presentation/README.md` の「スライドの書き方」「個人名・秘匿情報の扱い」「主張の線」「用語と出典」，`presentation/qa_defense_matrix.md` ，`plans/research-context.md` の「発表の軸」「主結果の報告方針」．
- 確認のみで，スライドは修正しない．スライドごとに次を判定し，修正案の一覧を作る．
  - **構成**：新構成のどのスライドに当たるか（旧構成のまま・欠けている・余っているスライドの特定）．A～D が 定義 / 実験の概要 / 結果・考察 の 3 枚になっているか．
  - **書き方**（研究者の指定 6 点）：文章の長さ，要素の列挙が箇条書きか，記号・用語の定義のまとめ方（全体はスライド 2，パートごとは各パートの最初），出典が文中にないか（右肩の [n] と下部の薄い文字），出典にプログラム名・スクリプト名・run 名がないか．
  - **数値**：スライドの数値を storyline・qa の値（出典の CSV）とスクリプトで照合（034 と同じ方法，丸め前の値から資料の桁で丸める）．
  - **用語と主張**：使わない指標名（Balanced Accuracy，マクロ F1，単独の正解率），「B が最良」等の言い過ぎ，仮説を事実として書いていないか，寺田寅彦の例外・限界の記載，講義の回・頁の出典．担当間の不統一（推論方式，チャンク長，指標名，記号）．
  - **図**：`presentation/figures/` の現行版（031・035 で再生成した日本語表記の図）を使っているか．PDF のページを画像で確認し，文字のはみ出し・図の崩れ・読みにくさを指摘（目視と明記）．
  - **個人名・秘匿情報**：氏名・学籍番号・メールアドレス・ローカルパス等が，スライド本文・発表者ノート・図の中の文字・ファイルのメタデータ（pptx の作成者・最終更新者，PDF の Author 等）に含まれていないか．**見つけた文字列そのものは報告・出力に書かず**，スライド番号・箇所・種類のみを報告．
- pptx の読み取りは `uv run --with python-pptx` 等で一時的に行い，依存関係の定義ファイル（`pyproject.toml` ， `uv.lock` ）は変更しない．PDF は Read ツールで画像として確認（1 回 20 ページまで）．
- 出力：スライドごとの修正案の一覧（スライド番号，新構成での位置，判定項目，現状，修正案，修正に必要な作業（文言の修正 / 数値の差し替え / 図の差し替え / 新規作成）），全体の所見（構成の過不足，担当間の不統一）．`outputs/review_037/` に保存（書き込めない場合は報告本文に記載）．報告と出力に個人名を含めない．

## Target File Paths

- なし（リポジトリのファイルは変更しない．出力は `outputs/review_037/` と scratchpad）

## Mandatory Constraints

- Comply with `.claude/rules/research-coding.md` (loaded automatically).
- pptx・pdf を変更しない．`presentation/` の他のファイル・`plans/` ・`src/` ・`scripts/` ・`configs/` を変更しない．
- 依存関係の定義ファイルを変更しない．
- 個人名・秘匿情報を報告・出力・ファイル名に書かない．
- コミットしない．

## Verification Criteria

- [ ] pptx の全スライドが一覧に含まれる（スライド数を報告）．
- [ ] 数値の照合件数と不一致の一覧を報告（照合はスクリプト，丸め前の値から）．
- [ ] 書き方 6 点の判定をスライドごとに報告．
- [ ] 個人名・秘匿情報の確認結果（箇所と種類のみ，文字列は書かない）と，pptx・pdf のメタデータの確認結果を報告．
- [ ] 新構成に対する過不足（欠けているスライド，旧構成のまま残っているスライド）を報告．

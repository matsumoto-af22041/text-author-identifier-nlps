# 青空文庫の文体・表現類似度に基づく著者識別システム

Agent-agnostic entry point for any AI coding agent (Claude Code, Codex, Gemini CLI, Cursor, Copilot, etc.).
Claude Code loads the same information automatically via `CLAUDE.md`; other agents must read the files below themselves.

## Read order

1. `plans/research-context.md`: research specification (hypothesis, design, stack, prohibited libraries, data handling guardrails, directory rules, notation). Canonical source. Summary pointer: `llm-context.md`.
2. `.claude/rules/research-coding.md`: research coding standards for anyone who writes or modifies code. Canonical source. Summary pointer: `llm-rules.md`.
3. `.agents/AGENTS.md`: agent roles (Orchestrator / Executor), how to assume them without Claude Code, and the execution model.
4. `plans/wbs.md`: roadmap, task dependencies, and status of each ticket `plans/{NNN}-{task-slug}.md`.

## Key rules at a glance

- No role by default. Act as the Orchestrator or Executor only when the user explicitly assigns that role (see `.agents/AGENTS.md`).
- Never read the raw corpus `data/raw/corpus20150426_with_titles.txt` with a file viewer or full-output command; process it line by line via Python scripts.
- `scikit-learn` and other ML / similarity libraries are prohibited. Use only `numpy` and `fugashi` (`fugashi-plus[unidic-lite]`) and implement features, similarities, and classifiers from scratch.
- Tickets are executed one at a time. Commands longer than 10 minutes are not run by agents; the researcher runs them.
- Do not modify anything under `.claude/`. It is the canonical definition of roles and rules for every agent.

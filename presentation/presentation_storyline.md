# 最終プレゼンテーション構成案・主張ストーリーライン（Slide Blueprint）

## 発表の軸と問い

- **発表の軸（2026-11-24 改訂， `plans/research-context.md` ）**：
  **「4 つの観点（A～D）で文章の類似度を測り，未知作品の著者を識別できるのはどれか，できないならなぜか」**．
  - **どれか（Slide 18）**：未知作品（作品間分割）で基準値を大きく上回るのは内容に依存しない A・B．内容語系の C・D は作品内分割では高いが，作品が変わると大きく低下（ `full_006` ）．
  - **なぜか（Slide 19-20）**：同じ作品のチャンクは題材・登場人物・底本の表記を共有し，Train と Test に分かれると作品の一致で識別できてしまう（トピック漏洩）．B の同じ表現で語の種類だけを付属語と内容語で入れ替えた統制比較では，作品内分割では内容語，作品間分割では付属語が判別で上回る（ `full_006` ， `sensitivity_029_L*` ）．
  - **旧 Core Message の位置付け**：「情報検索では捨てる語が，著者識別では手がかりになる」は発表の主題ではなく，Slide 20 の統制比較の位置付け．
    - 第 5 回 p.11 は助詞・助動詞を「どの文書にも均質に現れる語」として索引語から外す不要語とし，第 5 回 p.14-16 は『坊っちゃん』の頻度上位（て・だ・た・は・を…）を除いて tf・idf で並べ替えると「山嵐」「シャツ」等の題材語が上位に来ることを示す．
    - 統制比較は，この捨てられた側の付属語（助詞・助動詞，第 2 回 p.11）と内容語の対比．
    - 結果：未知作品の判別（作家別正解率の平均）では，内容語の語彙選択を変えても付属語が内容語を上回る．同一著者の文章を上位に並べる力（作家別 MAP の平均）では差は小さく，作品固有の語を除いた内容語とはほぼ同等（Slide 20，補助 S1）．
- **ストーリーの骨格（単なる機械学習の分類発表にしないための鉄則）**：
  - 課題 2 の主役は **「文章間の類似度（Similarity）」**．いきなり「4 クラス分類の正解率が何 % だった」と話すのではなく，すべての検証で以下の 2 段階でデータを提示：
    - **【類似度の妥当性検証】** 提案した類似度尺度で，**「同じ著者の文章ペアの平均類似度 $\mu_{\text{same}}$ が高く，別の著者の文章ペアの平均類似度 $\mu_{\text{diff}}$ が低くなる（ギャップ $\Delta S = \mu_{\text{same}} - \mu_{\text{diff}} > 0$ が開く）」** か（独自設計の指標）．同一著者の Train チャンクが類似度順の上位に並ぶかを作家別 MAP の平均で測る（特徴量間比較の主指標）．
    - **【類似度に基づく著者判別】** その性質を利用して最も類似度が高い登録著者を当てにいく（重心法 / $k$-NN 法）と，**「未知の作品でも作家ごとにどれだけ当てられるか」**（作家別正解率の平均・作家別 F 値の平均）．
- **4 つの類似度観点（担当 A～D）の位置付け**：
  - ①表層・文字づかいと句読点（担当 A），②品詞の並びと付属語（担当 B），③使われている内容語（担当 C），④内容語の共起による潜在意味（担当 D）．
  - 4 観点を対等に並べ，作品間分割で識別できるかを比べる．B の付属語条件と内容語対照条件の統制比較（表現をそろえて語の種類だけを差し替え）は「なぜか」の根拠の 1 つ（Slide 20）．
- **類似度はコサイン係数（第 5 回 p.26，第 3 回 p.25）に統一**．構想発表 p.4 の「入力文章と各人物の特徴をコサイン類似度で比較」と一致．

## プレゼンで使用する「評価データ（指標・図表）」の定義（Slide 2 の素材）

班員全員が実装・実験スクリプトから共通して採るデータ（出力は 006 の `scripts/run_experiments.py` ）：

- **作家別 MAP の平均（特徴量間比較の主指標）**：
  - 各 Test チャンクを検索質問，同一著者の Train チャンクを適合文書とし，Train 全件をコサイン類似度の降順に並べた AP（第 5 回 p.31 を参考にした独自設計，分母は適合文書数）を作家ごとに平均し 4 作家で単純平均．類似度の順位のみに依存するため，類似度の値の分布が異なる特徴量間でも比べられる．基準値はランダムな並びの期待値（ $L = 500$ の Inter-work，間引きありで 0.260）．
- **同一著者 vs 異著者の平均類似度とマクロ版ギャップ（ $\mu_{\text{same}}, \mu_{\text{diff}}, \Delta S_{\text{macro}}$ ，独自設計）**：
  - 4×4 作家間平均類似度行列の対角 4 要素（同一著者）の平均と非対角 12 要素（異著者）の平均の差 $\Delta S_{\text{macro}}$ （ `delta_s_macro` ）を主とし，ペア単位のミクロ版（ `delta_s_micro` ）を併記．値の分布が特徴量ごとに異なるため，同じ特徴量内の比較（チャンク長別等）に限って使う．
- **同一著者ペア vs 異著者ペアの類似度分布ヒストグラム（2 色重ね合わせ）**：
  - 横軸に類似度，縦軸にペア頻度．本人ペアと他人ペアの分布の分離度を示す（D は負値を含むため横軸 $[-1, 1]$ ）．
- **4×4 作家間平均類似度ヒートマップ**：
  - 行は照会（Test）作家，列は登録（Train）作家．対角成分が非対角成分より高くなるかを示す．
- **著者判別の指標（作家別正解率の平均 / 作家別 F 値の平均 / MRR）と混同行列**：
  - 作家別正解率は第 5 回 p.28 の再現率に第 6 回 p.44 の正解率を作家ごとに当てはめたもの，F 値は第 5 回 p.28-29，作家別の値の単純平均は独自設計，MRR は第 5 回 p.31．基準値は作家別正解率の平均 0.25，作家別 F 値の平均 0.233（ $L = 500$ ），MRR 0.521．
  - Inter-work（LOWO 9 fold）では全 fold の予測を合算した Pooled 混同行列から作家別の値を算出．
  - 正解率（全 Test チャンクでの集計）は漱石の正誤に支配されるため載せない．
  - 同点（最大スコアを複数作家が共有）は誤判別として扱い，混同行列の「同点」列と同点件数を併記（008）．本採用の A～D の全条件で同点 0 件．アブレーションの一部の $k$-NN（ `A[blocks=symbol]` の $L = 500$ ，B の `words` の付属語・内容語の $L = 100$ ）では条件ごとに 0.2～4.0 件（5 シードの平均，間引きなしの Inter-work は 1 回の値， `summary.csv` の `n_ties` ）．
- **感度推移データ**：チャンク文字数 $L \in \{100, 500, 1000\}$ ，推論方式（重心法 vs 作家別上位 $k$ 平均， $k \in \{1, 3, 5, 10, 20\}$ ），B の付属語 vs 内容語対照，各担当のアブレーション．

## 班員への実装・スライド作成指示の連動ルール

- **各自が自分のパート（Slide 6～17）で必ず出すデータ**：
  - 作家別正解率の平均だけでなく，必ず **作家別 MAP の平均** と **同一著者平均類似度 $\mu_{\text{same}}$ vs 異著者平均類似度 $\mu_{\text{diff}}$ （およびギャップ $\Delta S_{\text{macro}}$ ）** を併記し，「自分の特徴量で類似度を測ると，本人同士がこれだけ高く，他人同士がこれだけ低くなった．だからこれだけ判別できた」という流れでスライドを作成．基準値を必ず併記．
  - 各パートは 定義 / 実験の概要 / 結果・考察 の 3 枚．パート固有の記号・用語は「定義」のスライドにまとめる．
  - 推論方式は重心法で統一（ $k$-NN 法は補助 S5 の比較表のみ）．
  - 数式・手法の出典（講義資料の回・頁，または「独自設計」）は文中に書かず，右肩の番号とスライド下部の脚注で示す（ `presentation/README.md` の「スライドの書き方」）．
- **統合実験スクリプト（001・006・008）との対応**：
  - `src/evaluator.py` と `scripts/run_experiments.py` は，すべての実験条件で作家別 MAP の平均，作家別正解率の平均，作家別 F 値の平均，MRR と同時に `mu_same` （ $\mu_{\text{same}}$ ）， `mu_diff` （ $\mu_{\text{diff}}$ ）， `delta_s_macro` ・ `delta_s_micro` （ $\Delta S$ ），4×4 作家間平均類似度行列を算出して `outputs/` に保存．同点件数とゼロベクトルの照会チャンク数も記録（008）．
  - スライドに載せる数値は 006 の Full Experiment の出力（ `outputs/full_006/` ）から転記し，本資料と発表者ノートに run 名を併記．発表に使う図は `presentation/figures/` にコピー済み．

# 形態素解析辞書 `unidic-lite` 採用の妥当性とフル版 `unidic` との比較整理

## 概要と技術選定の背景

- **選定環境・パッケージ**：Python 3.13 + `fugashi-plus[unidic-lite]`（Cython 3.0 ベースの MeCab ラッパー・型ヒント同梱の Python 3.13 対応版，および UniDic 2.1.2 ベースの軽量同梱辞書）
- **選定理由**：OS 側への C++ ライブラリや外部辞書の個別インストール作業を不要とし，かつ本家 `fugashi` の Python 3.13 / Windows 環境でのビルド問題と型補完の欠如を解消して，`uv sync` 単一コマンドで班員 4 名の環境（macOS / Windows 混在）に完全に同一の形態素解析環境を再現するため．

---

## フル版 `unidic` と `unidic-lite` の仕様比較

| 比較項目 | フル版 `unidic`（現代書き言葉 UniDic） | `unidic-lite`（採用版・UniDic 2.1.2 ベース） | 本実験（青空文庫の著者識別）への影響 |
| :--- | :--- | :--- | :--- |
| **辞書サイズ・導入手順** | 展開後 約 800 MB<br>（別途 `python -m unidic download` が必須） | 約 50 MB<br>（`uv sync` のみで完結・追加ダウンロード不要） | 環境構築の再現性向上とトラブル防止に直結 |
| **収録語彙の範囲** | 現代の Web 新語・最新トレンド語・膨大な現代固有名詞を収録 | 現代新語や肥大化した固有表現を削ぎ落とした標準的な現代語基本辞書 | 明治〜昭和初期の文学作品が対象のため，現代 Web 新語の有無は解析精度に無関係 |
| **形態素属性（フィールド数）** | 全 29 フィールド<br>（語種 `goshu`・アクセント型 `aType` 等を含む） | 主要 17 フィールド<br>（品詞 `pos1`〜`pos4`・活用型 `cType`・活用形 `cForm`・語彙素読み `lForm`・語彙素 `lemma`・書字形 `orth`・発音形 `pron` 等） | 特徴量抽出で使用する属性はすべて `unidic-lite` の 17 フィールド内に網羅 |

---

## `unidic-lite` 採用による弊害の有無と批判的検討

### 1. 現代新語・最新固有表現の削減による影響（影響なし）

- **辞書の差異**：フル版 `unidic` と `unidic-lite` の語彙数・ファイルサイズの差の大半は，現代の Web コーパスから収集された新語や現代固有名詞（商品名・現代の地名・人名・ネットスラング等）の有無に起因．
- **本課題における妥当性**：
  1. **対象時代の整合性**：実験対象は明治後期〜昭和初期の青空文庫 4 作家（夏目漱石・太宰治・寺田寅彦・田山花袋，計 9 作品）であり，現代のネットスラングや最新の固有名詞は一切出現しない．
  2. **文体識別（Stylometry）の目的との合致**：本研究の主眼は「作品固有のトピック語や固有名詞に依存せず，助詞・助動詞・接続詞といった機能語や品詞遷移パターン（POS N-gram）で著者の文体を見分ける」点にあり，機能語および基本語彙の解析精度はフル版と `unidic-lite` で完全に同一．

### 2. 形態素属性フィールド数の削減（29 個 → 17 個）による影響（注意点あり）

- **保持されている主要 17 フィールド**：
  - 品詞階層：`pos1`（大分類），`pos2`（中分類），`pos3`（小分類），`pos4`（細分類）
  - 活用情報：`cType`（活用型），`cForm`（活用形）
  - 表記・語彙素情報：`lForm`（語彙素読み），`lemma`（語彙素・基本形），`orth`（書字形出現形），`pron`（発音形出現形），`orthBase`（書字形基本形），`pronBase`（発音形基本形）等
- **本システムの実装との対応**：
  - 【担当 B（品詞 N-gram・機能語モジュール）】および【担当 C（内容語 TF-IDF モジュール）】で参照するのは，品詞分類（`pos1`, `pos2`）と語彙素（`lemma` または表層形 `surface`）のみであり，削減されたアクセント型（`aType`）やアクセント結合型（`aConType`）は一切使用しない．
- **質疑応答で注意すべき唯一の技術的トレードオフ（語種情報 `goshu` の欠落）**：
  - フル版 `unidic` の第 13 フィールドには，単語の出自を表す **語種（`goshu`：和語・漢語・外来語・混種語・記号）** が収録されているが，`unidic-lite` の 17 フィールドではこの `goshu` が省略されている．
  - したがって，「作家ごとの漢語率 vs 和語率の違い」を辞書引きで直接算出することはできない．ただし，本研究では【担当 A（表層・文字種・文体統計モジュール）】において「漢字・ひらがな・カタカナの字種構成比」を文字レベルで直接算出して代替しているため，特徴量空間としての情報欠損は生じない．

### 3. フル版・軽量版に共通する本質的限界（近代文語・歴史的仮名遣いの問題）

- **現代語 UniDic 共通の限界**：フル版 `unidic` も `unidic-lite` も，ともに「現代語書き言葉（CWJ）」を基準とした辞書であり，国立国語研究所が別途配布している「近代文語 UniDic」や「近代口語（明治・大正期）UniDic」とは異なる．
- **対象 9 作品における対策**：
  - 対象 4 作家（漱石・太宰・寅彦・花袋）の抽出 9 作品が青空文庫の「新字新仮名」版であるか，あるいは旧仮名遣い（例：「思ふ」「てふ」「〜やうだ」）や当て字（例：「矢張」「成程」「沢山」）を含むかを Ticket 0 の前処理スクリプトで事前に定量検査する．
  - 漢字表記の揺れ（「やはり」vs「矢張」など）については，表層形（`surface`）や書字形（`orth`）ではなく，UniDic の強みである **語彙素（`lemma`）** を特徴量キーとして使用することで表記揺れを正規化・吸収する設計とする．

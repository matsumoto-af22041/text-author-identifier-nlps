### Q1．なぜ 30 作品あるのに 4 作家（9 作品）しか使わないのか

- **既定仕様**：4 作家（夏目漱石 3・太宰治 2・寺田寅彦 2・田山花袋 2）の計 9 作品に固定（ `configs/default.yaml` の `targets` ）．
- **切り替えフラグ**：なし．
- **数値（ `verify_qa_points` ，確認）**：全 30 作品・25 作家のうち 2 作品以上を持つ作家は 4 名のみ（夏目漱石 3，太宰治 2，寺田寅彦 2，田山花袋 2），残り 21 作家は各 1 作品．
- **回答**：
  - 未知作品での著者識別（Inter-work）には 1 作家あたり 2 作品以上が必須．条件を満たす作家がちょうど 4 名．
  - 4 名はいずれも明治後期～昭和初期の口語体．文語体（福沢諭吉・幸田露伴等）や翻訳文学（ディケンズ等）を混ぜると，文体ではなく時代・翻訳調の識別になる交絡を避けられる．
- **出典**：Inter-work を主評価とする設計は独自設計（同じ作品のチャンクは互いに独立でないため，research-context の「データ分割」）．

- **既定仕様**：Inter-work（LOWO 9 fold，Pooled）を主評価，Intra-work（作品単位の層化ランダム分割，5 シード）を併記．

- **数値（ `full_006` ，作家別 MAP の平均 / 作家別正解率の平均）**：

| 特徴量 | Intra-work | Inter-work | 変化（MAP / 作家別正解率） |
| :--- | :--- | :--- | :--- |

| B | 0.502 ± 0.006 / 0.806 ± 0.034 | 0.420 ± 0.004 / 0.581 ± 0.011 | −0.082 / −0.225 |

- **回答**：

- **出典**：学習・テストの分割例は第 6 回 p.42．Intra-work / Inter-work の両方で評価する理由は独自設計．

- **数値**：
  - 二乗ノルム割合（010，全チャンクの平均）：既定仕様は Bi-gram / 記号 = 0.72 / 0.28（ $L = 100$ ），0.57 / 0.43（500），0.52 / 0.48（1000）．字種を含む旧案は字種が 0.98～0.99，旧案＋Min-Max は Bi-gram が 0.88～0.96（ `presentation/qa_verification_instructions.md` の補足表）．
  - アブレーション（ `full_006` ， $L = 500$ ，作家別 MAP の平均 / 作家別正解率の平均）：

| 設定 | Intra-work | Inter-work |
| :--- | :--- | :--- |

| `scaling="minmax"` | 0.588 ± 0.003 / 0.973 ± 0.009 | 0.400 ± 0.005 / 0.514 ± 0.013 |
| `blocks="bigram"` | 0.581 ± 0.006 / 0.883 ± 0.021 | 0.422 ± 0.004 / 0.525 ± 0.020 |

- **回答**：
  - 正規化は中立な前処理ではなくブロックの重みを暗黙に決める操作．二乗ノルム割合の実測で単一ブロックに支配されない既定仕様を選んだ．

### Q8．C の idf の式は．全チャンクに出る語の重みが 0 になるのは問題ではないか

- **既定仕様**：$\text{tf}(t, d) = \frac{\text{出現回数}}{\text{総形態素数}}$ ， $\text{idf}(t) = \log \frac{N}{\text{df}(t)}$ （自然対数，補正項なし），重み $w_{dt} = \text{tf}(t, d) \cdot \text{idf}(t)$ ．索引語は名詞・動詞・形容詞，キーは語彙素， `max_features=2000` ．
- **切り替えフラグ**：なし．
- **数値（004・012， `scripts/verify_word_tfidf.py` ）**：$\text{idf} = 0$ の語は $L = 100$ で 0 語， $L = 500$ で 0 語， $L = 1000$ で 1 語（ `為る` ）．Intra-work（ `seed=42` ）と LOWO 9 fold の全 10 分割で同数．語彙内の最大 $\text{df} / N$ は $L = 100$ で 0.7585， $L = 500$ で 0.9957．
- **回答**：
  - 全チャンクに出る語の重みが 0 になるのは，第 5 回 p.11 の「どの文書にも均質に現れる語は索引語として不適切」と整合する挙動．実データでは該当語がほぼなく，情報の欠落は無視できる大きさ．
  - df と語彙辞書は Train のみから構築し，Test のみに現れる語は無視（情報漏洩の防止）．
- **出典**：tf は第 5 回 p.12，idf は第 5 回 p.13，索引語と不要語は第 5 回 p.11．

  - $K$ 別（ `full_006` ， $L = 500$ ，間引きあり，作家別正解率の平均 / 作家別 MAP の平均）：

| $K$ | Intra-work | Inter-work |

  - 間引きなしでは漱石が Train の約半数（ $L = 500$ の Inter-work で漱石の作家別 Train チャンク数の fold 平均 712.0 に対し寺田 157.3， `centroid_norm_ABCD` ）．
  - 漱石以外のチャンク中の漱石予測割合（重心法， $L = 500$ ， `exclusion_summary_ABCD` ）：C は間引きなし 0.583 → 間引きあり 0.351 ± 0.053，B は 0.150 → 0.146 ± 0.009．
  - 間引きなしで `per_author` の作家別正解率の平均が下がる（Q11：B の $k = 5$ で 0.588 → 0.408）．
- **回答**：Train のチャンク数の偏りが特定の作家への予測の集中を生むため（013～015 の実測）．Test は間引かず，特徴抽出器の `fit` は間引き後の Train のみ．間引きの有無で作家別 MAP の平均の基準値が大きく変わる（0.260 vs 0.157）ため，間引きあり・なしの MAP の比較は基準値との差で行う．
- **既知の限界**：Inter-work では Test 作家だけ Train に 1 作品少なく，作品の多様性の差は間引きで消えない（015）．
- **出典**：独自設計（013～015 の実測）．

### 漱石への偏りと重心の割り増しは結果を歪めていないか

- **既定仕様**：9 作品版・間引きあり・重心法が主結果．作品除外（8 作品版）と割り増し係数の実測は補助実験（ `scripts/summarize_exclusion.py` ， `scripts/measure_centroid_norm.py` ）．
- **数値**：
  - 作品除外（漱石の 1 作品を除いた 8 作品版 3 通り − 9 作品版， `exclusion_summary_ABCD` ，間引きあり）：A～D・全 $L$ ・重心法と `per_author` $k = 5$ で，作家別正解率の平均の変化は −0.075～+0.055，作家別 MAP の平均の変化は −0.017～+0.025．B の重心法（ $L = 500$ ）は 坊っちゃん除外 −0.054，こころ除外 +0.053，三四郎除外 −0.033．
  - 漱石以外のチャンク中の漱石予測割合（ $L = 500$ ，重心法，間引きあり，9 作品版）：A 0.195 ± 0.013，B 0.146 ± 0.009，C 0.351 ± 0.053，D 0.345 ± 0.044．
  - 割り増し係数の比（漱石 / Test 作家，fold 単位， $L = 500$ ，間引きあり， `centroid_norm_ABCD` ）：A 0.97～1.11，B 0.99～1.02 でほぼ 1．C 0.96～1.17，D 0.93～1.43（D の `lowo_terada_0` が最大）．
- **回答**：
  - 作品除外による変動は作家別正解率の平均で ±0.05 程度（B）．Train に残る漱石の作品によって結果は動くが，付属語と内容語・特徴量間の大小関係を覆す大きさではない（Q5 の差は 0.1 以上）．
  - 重心とのコサインは作家内の平均類似度が小さい作家ほど $1 / \|\hat{c}_a\|$ で割り増される．A・B では作家間でほぼ同じで影響は小さい．C・D では最大 1.43 倍の差が残り，C・D の低さの一部はこの割り増しの偏りによる可能性（仮説）．
- **出典**：独自設計（013～015，027 の実測）．

### MAP の差が小さいのに付属語が有効と言えるのか

- **既定仕様**：主結果は `bal` （fit・検索対象・重心とも間引き後の Train）．内容語の語彙は fit 用 Train の df 上位 `max_features=1500` 語．語彙選択の再設計は行わず，感度を併記（research-context の「主結果の報告方針」）．
- **数値（ `sensitivity_029_L{100,500,1000}` ，Inter-work， `words` ，付属語 − 内容語）**：

| 条件 | fit（語彙） | 検索対象・重心 | MAP の差 $L = 100$ / 500 / 1000 | 作家別正解率の平均の差 $L = 100$ / 500 / 1000 |
| :--- | :--- | :--- | :--- | :--- |
| `bal` （主結果） | 間引き後 | 間引き後 | +0.014 / +0.033 / +0.049 | +0.092 / +0.186 / +0.219 |
| `nobal` | 全件 | 全件 | +0.004 / +0.004 / +0.008 | +0.097 / +0.196 / +0.215 |
| `fitfull_poolbal` | 全件 | 間引き後 | +0.001 / +0.006 / +0.015 | +0.090 / +0.178 / +0.211 |
| `fitbal_poolfull` | 間引き後 | 全件 | +0.011 / +0.029 / +0.047 | +0.103 / +0.208 / +0.227 |
| `drop_single_author` | 間引き後（1 作家にしか出ない語を除外） | 間引き後 | +0.005 / +0.006 / +0.003 | +0.038 / +0.085 / +0.104 |

  `drop_single_author` では内容語の作家別正解率の平均が上がる（ $L = 500$ ：0.338 → 0.439，$L = 1000$ ：0.350 → 0.465）．付属語はほぼ不変（0.524 → 0.524）．

- **回答**：
  - MAP の差は内容語の語彙選択（df 上位 1500 語を fit 用の Train から選ぶ処理）に依存する．fit 用 Train の構成を替えただけで差が +0.006～+0.033（ $L = 500$ ）の範囲で動く（028，確認）．Train で 1 作家にしか出ない語を除いた内容語とは MAP でほぼ同等（+0.003～+0.006）．
  - 作家別正解率の平均の差も語彙選択に依存するが，どの条件でも付属語が上（ $L = 500, 1000$ で +0.085～+0.227， $L = 100$ で +0.038～+0.103）．
  - 結論：「未知作品の判別では，内容語の語彙選択を変えても付属語が内容語を上回る．同一著者の文章を上位に並べる力（MAP）では差は小さく，作品固有の語を除いた内容語とはほぼ同等」．MAP の差を単独の根拠にはしない．
  - 漏洩のない操作のみを使用．Test 作家の情報を使う 028 の診断値は使わない．
- **出典**：AP は第 5 回 p.31 を参考にした独自設計．語彙選択の感度分析は独自設計（028，029）．

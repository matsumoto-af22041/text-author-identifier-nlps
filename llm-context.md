# Research Context (pointer)

The research specification of this project lives in **`plans/research-context.md`**. Read that file in full before planning or writing code.

## Why this file does not hold the content

- `plans/research-context.md` is owned and updated by the Orchestrator as the research design evolves.
- The Orchestrator may write only under `plans/`, so a copy here could not be kept in sync. Keeping a single source prevents agents from following an outdated specification.
- Claude Code imports it automatically via `CLAUDE.md`. Other agents must read it explicitly.

## What it covers

- Research Overview: research question, proposed approach, primary stack
- Experimental Design: target authors and works, Intra-work / Inter-work splits, chunking, similarity measures, classifiers, primary metrics, known confounds
- Target Computational Stack, including **Prohibited Tools / APIs** (no `scikit-learn` etc.)
- **Data Handling Guardrails**: never read the raw corpus directly; stream it via Python scripts
- Directory Structure & Asset Placement Rules
- Domain Glossary & Mathematical Notation (symbol ↔ variable name mapping)

## Editing rule

- Do not edit this file to change the specification. Changes go to `plans/research-context.md` through the Orchestrator or the researcher.
